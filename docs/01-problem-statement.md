# 01 — Problem Statement

## Problem

部分 KTV 使用情境中缺乏、取消或降低即時評分與互動功能，造成唱歌時的競賽與遊戲體驗缺口。這不代表市面上完全沒有 KTV 評分；目前是使用者提供的問題背景，市場涵蓋率與需求強度為 TBD，尚無訪談量化資料。

## Current User Workaround

可能以朋友口頭評價、自訂遊戲、換到有評分的設備，或改用個人 karaoke app 補足體驗。這些是待訪談驗證的 workaround，不能假定每位使用者都如此。

## Why Existing Solutions Do Not Fully Solve It

綁定特定設備的評分不一定能帶進其他包廂；需要在 app 重新找歌／播放的流程可能打斷 KTV 現有點歌；專業練唱工具的學習成本也未必符合聚會需求。以上是產品機會假設，並非對所有競品功能的斷言。

## Opportunity

以可替換音訊來源接收現場音訊，提供即時且誠實標示限制的娛樂回饋。以 Unknown Song Mode 降低辨識失敗對流程的影響。先驗證混音環境中的 pitch confidence 與可理解的回饋，再評估排行榜；不以辨識歌名等同取得音符 reference。

待驗證：設定步驟、分數可信度、對延遲的容忍、朋友交談干擾、手機位置，以及是否願意在真實包廂持續使用。
