# 03 — Stakeholders and Personas

以下為需求角色，不是假造訪談人物或人口統計。

| Persona | 目標 | 重要需求 | 不假定的能力 |
|---|---|---|---|
| Casual KTV User | 唱歌、看分數、玩 Combo | 低設定、即時易懂回饋、辨識失敗仍可玩 | 不需懂 MIDI 或專業聲樂分析 |
| KTV Party Group | 朋友一起唱、比較戰績與遊戲化 | 可理解且公平的結果、未來多人與 ranking | 初期不假定可自動分離／識別每位歌手 |
| Advanced / Hardware User | 未來接 direct audio input | 可替換 AudioSource、裝置生命週期與品質資訊 | 不要求一般使用者自備 mixer |

Stakeholders：專案擁有者負責範圍與決策；開發者／AI agent 維護規格和驗證；測試參與者提供經同意的實境觀察；KTV 業者可能是未來硬體協作方，尚非已確認合作。第三方辨識與開源維護者提供外部能力，必須隔離依賴。

待釐清：聚會如何輪唱、是否比較不同歌曲、裝置共享方式、音訊取得與參與者告知。TBD 不代表已授權建立帳號、個資、聲紋識別或雲端音訊儲存。
